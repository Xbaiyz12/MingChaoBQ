# MingChaoBQ - 鸣潮表情包插件

> 项目地址：https://github.com/Xbaiyz12/MingChaoBQ

基于 [GsCore](https://github.com/Genshin-bots/gsuid_core) 的鸣潮表情包插件。

## ✨ 功能特性

- 🎲 随机表情 — 从全部表情里随机发一张
- 🎨 按画师/角色/表情名检索 — 画师模糊搜索，角色支持别名，表情精准匹配（本地图片）
- 📋 列表图 — 卡片展示画师和角色，每个角色都有独立图标
- 🖼️ 帮助图 — 基于 GsCore `get_new_help` 渲染
- 🔒 群白名单 / 黑名单 — 可开关，只允许指定群使用
- 🌐 API 表情自动保存本地，按角色分类、按内容去重
- 👆 戳一戳 — 可全局开启，也可按群固定角色
- 📊 发送统计 — 分别提供戳一戳用户排行与角色名发送排行图
- 🧹 重复表情查重 — 全库扫一遍找出同一张图被重复收录的，渲染成报告图
- ⏰ 索引自动更新 — 每天在控制台设定的时间自动重扫一次，手动加图/API 存图不用再管
- 🎛️ 网页控制台配置 — 所有配置项可在控制台修改，即时生效

## 📦 安装

```bash
cd gsuid_core/plugins
git clone https://github.com/Xbaiyz12/MingChaoBQ.git
```

装好后在网页控制台把插件和 `bq` 前缀打开，再发一次 `bq更新索引` 生成索引。

## 🐧 Linux / Docker 部署说明

- **下载器**：API 取图与保存本地优先调用系统 `curl`（绕开 Cloudflare 的 TLS 指纹拦截），没有 `curl` 时自动回退 `aiohttp`。官方 Docker 基础镜像已自带 `curl`；裸机若缺可用 `apt install -y curl`（Debian/Ubuntu）或 `apk add --no-cache curl`（Alpine）。
- **代理**：`curl` 与 `aiohttp` 都会读取 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` 环境变量，挂了代理池的服务器无需额外配置。
- **中文字体**：渲染优先使用 GsCore 自带的 MiSansVF，不装系统字体也能正常出图；系统装了 Noto CJK / 文泉驿会自动作为回退（官方镜像已含 `fonts-noto-cjk`）。
- **路径**：索引里的图片路径统一使用正斜杠，索引文件在 Windows 与 Linux 之间搬运后仍可直接使用。

## ⏰ 索引自动更新

默认每天凌晨 **4:00** 自动重扫一次表情包目录 —— 手动往目录里加的图、API 保存的新图，都要重扫过才会进索引。控制台可改：

| 配置项 | 说明 |
|--------|------|
| 每日自动更新索引 | 开关，默认开启 |
| 自动更新索引·小时 / ·分钟 | 目标时刻，默认 4 点 0 分 |

- 改时间**立即生效**，不需要重载插件；
- 当天已经更新过（包括你手动发过 `bq更新索引`）就不会重复扫；
- 半夜停机错过了时间点，core 下次启动后会自动补上；
- 手动 `bq更新索引` 依然保留，临时加完图想立刻生效就用它。

## 🧹 重复表情查重

`bq查重` 会把全库本地表情扫一遍，找出**同一张图被重复收录**的（表情包合集里很常见：同一张素材被复制到多个画师/角色目录），渲染成报告图：每一组列出所有副本、标出建议保留的那张（绿框 = 体积最大的）、以及删掉冗余能省多少空间。

- 判据是 16x16 的感知哈希（dHash）：实测「同一张图重存/缩放」最大汉明距离 5，「不同图」最小 32，中间空档很大，所以默认阈值取 16 既不会漏也不会误报；
- 关键实现细节：**GIF 取「内容最丰富的一帧」而不是第 0 帧** —— 很多表情动图开头几帧是淡入空白帧，用第 0 帧比对会把整库空白首帧的图判成同一张（实测会误报出 1768 张一组）；
- 指纹有缓存（`data/MingChaoBQ/dedupe_hash.json`），第二次跑只算新增的图：6600 张全量首跑约 30 秒，之后约 2 秒；
- 想更严/更松可以跟阈值：`bq查重 10`（越小越严）。

## 🕹️ 指令

| 指令 | 说明 |
|------|------|
| `bq随机表情 [关键词]` | 随机发一张；关键词可为画师名/角色名/表情名，开了 API 优先时先问 API |
| `bq本地表情 [关键词]` | 同上但只查本地表情包，跳过 API |
| `bq搜索表情 关键词` | 按表情名/角色名/画师名搜索，渲染成淡蓝色列表图 |
| `bq列表` | 全部画师与角色概览图 |
| `bqXX列表` | 画师名看角色，角色名看表情，例：`bq捏捏列表` |
| `bq帮助` | 帮助图 |
| `bq设置戳一戳角色 角色名/随机` | 本群戳一戳固定角色（默认需群主/管理员权限） |
| `bq更新索引` | 重新扫描表情包目录（仅主人）。默认每天还会自动更新一次，见下方配置 |
| `bq查重 [阈值]` | 找出重复表情并渲染报告图（仅主人）。阈值是 16x16 感知哈希的汉明距离，默认 16，越小越严 |
| `bq戳一戳统计` | 群聊内查看被戳总次数与用户排行图（圆形头像 + 昵称 + QQ号） |
| `bq表情统计` | 查看按角色名统计的发送排行图 |
| `bq开启戳一戳` / `bq关闭戳一戳` | 戳一戳开关（仅主人） |
| `bq开启白名单` / `bq关闭白名单` / `bq查看白名单` | 白名单开关与查询（仅主人） |
| `bq添加白名单 群号` / `bq移除白名单 群号` | 白名单增删（仅主人） |
| `bq添加黑名单 群号` / `bq移除黑名单 群号` / `bq查看黑名单` | 黑名单增删查（仅主人） |

## 📁 数据目录

表情包放在 `gsuid_core/data/MingChaoBQ/` 下，索引由插件生成（`index.json`）：

```
data/MingChaoBQ/
├── 画师名/
│   └── 角色名/
│       └── 子分类/       # 可选，没有子分类就直接放图
├── API/                  # API 拉取的图，按角色分目录自动保存
├── icons/                # 自定义图标，覆盖插件内置图标
├── statistics.json       # 戳一戳与角色发送统计（自动生成）
├── banner.png            # 帮助图横幅（可在控制台指定文件名）
└── bg.png                # 帮助图背景（可在控制台指定文件名）
```

支持 `.gif` / `.png` / `.jpg` / `.jpeg` / `.webp`。新增或删除图片后执行一次 `bq更新索引`。
