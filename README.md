# MingChaoBQ - 鸣潮表情包插件

> https://github.com/Xbaiyz12/MingChaoBQ · 基于 [GsCore](https://github.com/Genshin-bots/gsuid_core)

## ✨ 功能

- 🎲 **随机 / 挑图**：按画师（模糊）、角色（含别名）、表情名（精准）出候选缩略图，回复编号即发
- 📋 **列表 / 帮助图**：卡片展示画师与角色
- ⬆️ **上传表情**：按层次落盘，画师名优先复用本地目录
- 🌐 **API 表情**：自动保存本地、按角色分类、按内容去重
- 👆 **戳一戳**：全局开关 + 按群固定角色，附被戳与角色发送统计图
- ⏰ **索引自动更新**：每天定时重扫，也可手动 `bq更新索引`
- 🔒 **群白名单 / 黑名单**：配置项在网页控制台修改，即时生效

## 📦 安装

```bash
cd gsuid_core/plugins
git clone https://github.com/Xbaiyz12/MingChaoBQ.git
```

装好后在控制台打开插件与 `bq` 前缀，发一次 `bq更新索引` 生成索引。

## 🕹️ 指令

| 指令 | 说明 |
|------|------|
| `bq随机表情 [关键词]` | 不带关键词随机一张；带关键词出候选缩略图，回复 `表情N` 发送第 N 个 |
| `bq本地表情 [关键词]` | 同上，但只查本地、跳过 API |
| `bq列表` / `bqXX列表` | 全部画师角色概览 / `bq捏捏列表` 看角色、`bq爱弥斯列表` 看表情 |
| `bq连发 [关键词]` / `bq三连` / `bq五连` | 一次连发多张（默认 3 张，走合并转发） |
| `bq帮助` | 帮助图 |
| `bq添加表情 [画师] [角色] [表情名]` | 上传表情（仅主人，图可跟命令一起发或 30 秒内补发） |
| `bq更新索引` | 重扫表情包目录（仅主人）；平时每天 4:00 自动重扫 |
| `bq戳一戳统计` / `bq表情统计` | 被戳用户排行图（仅群聊）/ 角色发送排行图 |
| `bq开启戳一戳` / `bq关闭戳一戳` | 戳一戳开关（仅主人） |
| `bq设置戳一戳角色 角色名\|随机` | 本群戳一戳固定角色 |
| `bq开启白名单` / `bq关闭白名单` / `bq查看白名单` | 白名单开关与查询（仅主人） |
| `bq添加白名单 群号` / `bq移除白名单 群号` | 白名单增删（仅主人） |
| `bq添加黑名单 群号` / `bq移除黑名单 群号` / `bq查看黑名单` | 黑名单增删查（仅主人） |

> 口语别名同样可用：`bq来一张`、`bq本地来一张`、`bq图库`、`bq来三张`、`bq传表情`、`bq刷新图库`、`bq表情排行`、`bq被戳排行`。
>
> 自动更新索引的开关与时刻可在控制台改，改完立即生效；当天已扫过不会重复扫，停机错过下次启动补上。

## 🔎 挑图

`bq随机表情 捏捏`（画师）/ `爱弥斯`（角色）/ `爱心`（表情名）都会先出一张候选缩略图，每个卡片带缩略图、`表情N` 编号、表情名与画师·角色：

- 回复 `表情2`（或 `2`、`第2个`）发送第 2 个；**只命中 1 张时直接发送**，不打扰你选；
- **「画师 + 角色」两级查询**：`bq随机表情 捏捏 今汐`（两个词顺序任意）只看该画师画的那个角色；
- 30 秒不回复、或回复看不懂的内容会提示有效范围，不会乱发；最多显示 50 个；
- **只写画师名时按角色轮流取，每个角色最多 10 个** —— 画师动辄上千张（捏捏 2263 张），顺序取会被同一个角色占满；
- 匹配顺序：画师+角色 → 表情精确 → 角色 → 画师 → 表情模糊 → 角色模糊 → 画师模糊；
- 缩略图取动图里「有内容的那一帧」，避免 GIF 开头的空白帧让整屏缩略图发白。

## ⬆️ 上传

`bq添加表情`（别名 `导入表情` / `上传表情`）**给到哪层就存哪层，空层不建目录**：

| 写法（都配一张图） | 落点 |
|------|------|
| `摸摸头` | `自定义/综合/摸摸头.gif`（只给表情名） |
| `今汐` / `捏捏` | 命中角色 → `自定义/今汐/…`；命中画师 → 该画师目录下 |
| `捏捏 比心` | `捏捏/比心.gif`（画师 + 表情名） |
| `捏捏 今汐 比心` | `捏捏/今汐/比心.gif`（三层） |
| `画师:新画师 角色:新角色 表情:新表情` | 本地没有也照此新建 |

- **新建画师一定用 `画师:名字`**：纯参数模式下认不出的词一律当表情名，不会乱建画师目录；
- 画师名优先复用本地目录（精确同名 → 忽略大小写与空格 → 模糊包含）；多个命中会列出来让你回序号；
- 名字含空格照原样写（如 `MIX CRAFT`）；上传完自动重建索引；权限默认仅主人。

## 📁 数据目录

`gsuid_core/data/MingChaoBQ/`，索引为自动生成的 `index.json`，图片支持 `.gif/.png/.jpg/.jpeg/.webp`：

```
data/MingChaoBQ/
├── 画师名/角色名/[子分类/]   # 子分类可选，直接放图也行
├── API/                      # API 拉取的图，按角色自动分目录
├── icons/                    # 自定义图标，覆盖内置图标
├── statistics.json           # 统计（自动生成）
└── banner.png / bg.png       # 帮助图横幅与背景（文件名可在控制台改）
```

新增或删除图片后执行一次 `bq更新索引`。

## 🐧 Linux / Docker

- **下载器**：API 取图优先调用系统 `curl`（绕开 Cloudflare 的 TLS 指纹拦截），没有 `curl` 时回退 `aiohttp`，官方镜像已自带；
- **代理 / 字体**：`curl` 与 `aiohttp` 都读 `HTTP_PROXY` 等环境变量；渲染优先用 GsCore 自带 MiSansVF，不装系统字体也能出图；
- **路径**：索引内路径统一用正斜杠，Windows 与 Linux 之间搬运后可直接使用。
