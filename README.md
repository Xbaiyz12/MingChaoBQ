# MingChaoBQ - 鸣潮表情包插件

> https://github.com/Xbaiyz12/MingChaoBQ · 基于 [GsCore](https://github.com/Genshin-bots/gsuid_core)

## ✨ 功能

- 🎲 **随机 / 挑图**：按画师（模糊）、角色（含别名）、表情名（精准）出候选缩略图，回复编号即发
- 📋 **列表 / 帮助图**：卡片展示画师与角色
- ⬆️ **上传表情**：按层次落盘，画师名优先复用本地目录
- 🌐 **API 表情**：自动保存本地、按角色分类、按内容去重
- 👆 **戳一戳**：全局开关 + 按群固定角色，附被戳与角色发送统计图
- ⏰ **索引自动更新**：每天定时重扫，也可手动 `bq更新索引`
- 🔒 **群白名单 / 黑名单**：配置项在网页控制台修改，即时生效

## 📦 安装

```bash
cd gsuid_core/plugins
git clone https://github.com/Xbaiyz12/MingChaoBQ.git
```

装好后在控制台打开插件与 `bq` 前缀，发一次 `bq更新索引`：**首次会自动下载内置表情包（约 143MB）**，这样开箱就有图，不会扫出 0 张；之后就是纯本地扫描。

## 🕹️ 指令

| 指令 | 说明 |
|------|------|
| `bq随机表情 [关键词]` | 随机发一张；关键词用来圈定范围（画师名/角色名/表情名） |
| `bq本地表情 [关键词]` | 同上，但只查本地、跳过 API |
| `bq列表` | 全部画师与角色的概览图 |
| `bqXX列表` | 出**缩略图列表**，回复 `表情N` 发送该张。`bq捏捏列表` 看画师、`bq达妮娅列表` 看角色、`bq捏捏 今汐列表` 看某画师画的某角色 |
| `bq连发 [关键词]` / `bq三连` / `bq五连` | 一次连发多张（默认 3 张，走合并转发）。**优先从 API 取图**，拿不满再用本地补齐 |
| `bq帮助` | 帮助图 |
| `bq添加表情 [画师] [角色] [表情名]` | 上传表情（仅主人，图可跟命令一起发或 30 秒内补发） |
| `bq更新索引` | **只扫描本地图库与内置表情包**（仅主人）；首次自动下载内置包，平时每天 4:00 自动重扫 |
| `bq下载表情包` | 手动下载/重装内置表情素材并重建索引（仅主人） |
| `bq网站搜索 关键词` | 搜**呜哇小站**上的角色与表情包（含各自张数、画师） |
| `bq画师列表` | 小站画师榜（按表情数排序，取前 20） |
| `bq拉取角色 角色名 [张数]` | 从小站拉取该角色的表情到本地并重建索引（仅主人；默认 20 张，上限 100） |
| `bq拉取画师 画师名 [张数]` | 同上，按画师拉取（仅主人） |
| `bq拉取表情包 包名或slug [张数]` | 同上，按指定表情包拉取（仅主人） |
| `bq戳一戳统计` / `bq表情统计` | 被戳用户排行图（仅群聊）/ 角色发送排行图 |
| `bq开启戳一戳` / `bq关闭戳一戳` | 戳一戳开关（仅主人） |
| `bq设置戳一戳角色 角色名\|随机` | 本群戳一戳固定角色 |
| `bq开启白名单` / `bq关闭白名单` / `bq查看白名单` | 白名单开关与查询（仅主人） |
| `bq添加白名单 群号` / `bq移除白名单 群号` | 白名单增删（仅主人） |
| `bq添加黑名单 群号` / `bq移除黑名单 群号` / `bq查看黑名单` | 黑名单增删查（仅主人） |

> 口语别名同样可用：`bq来一张`、`bq本地来一张`、`bq图库`、`bq来三张`、`bq传表情`、`bq刷新图库`、`bq表情排行`、`bq被戳排行`。
>
> **内置表情包**：插件本体不带图（clone 很快），首次 `bq更新索引` 会检测本地没有就自动下载一份素材包
> （画师「捏捏」每角色 10 张，约 143MB，解压进图库目录，**不覆盖你自己的图**）。控制台可关掉自动下载
> 「自动下载内置表情包」，或改「内置表情包地址」走国内镜像；失败了随时 `bq下载表情包` 重试。
>
> **索引只扫这两部分**：① 你自己放进 `data/MingChaoBQ/` 的图；② 自动下载的内置表情包（解压到同一个目录）。
> 想要更多素材，除了去**呜哇小站**（<https://emoji.wuwa.games>，免费的鸣潮表情包仓库）下载压缩包解压进
> `data/MingChaoBQ/`，也可以直接用命令拉：`bq网站搜索 今汐` 看小站有什么 → `bq画师列表` 看画师榜 →
> `bq拉取角色 今汐 30` / `bq拉取画师 雾雪 30` / `bq拉取表情包 wuwa-1-jinhsi 30` 拉到本地
> （拉取的表情存在 `API/角色名/` 下，同样会被索引扫到）。
>
> **API 等待上限**：控制台「API 等待上限（秒）」默认 3 —— 超过这个时间还没拿到 API 图就立刻改用本地，
> 避免戳一戳/随机表情被慢接口拖住（实测慢接口会让戳一戳等 15 秒以上）。想让 API 多等就调大，填 0 表示不限制。
>
> 自动更新索引的开关与时刻可在控制台改，改完立即生效；当天已扫过不会重复扫，停机错过下次启动补上。

## 🔎 列表挑图

**`bq随机表情` 只负责随机**（关键词只圈定范围）；要看清单、挑具体某张，用 `bqXX列表`：

| 写法 | 结果 |
|------|------|
| `bq捏捏列表` | 该画师的表情列表，**按角色轮流取、每个角色最多 10 个**（捏捏 2263 张，否则整屏都是同一个角色） |
| `bq达妮娅列表` | 该角色的表情列表 |
| `bq捏捏 今汐列表` | 某画师画的某角色的表情列表（两个词顺序任意） |

- 列表是一张**缩略图网格**：每张卡片带缩略图、`表情N` 编号、表情名与画师·角色，看一眼就知道是哪个；
- 回复 `表情2`（或 `2`、`第2个`）直接把第 2 张发出来；**只有 1 张时直接发送**；
- 30 秒不回复、或回复看不懂的内容会提示有效范围，不会乱发；最多显示 50 个，超出会提示还有多少个未显示；
- 缩略图取动图里「有内容的那一帧」，避免 GIF 开头的空白帧让整屏缩略图发白。

## ⬆️ 上传

`bq添加表情`（别名 `导入表情` / `上传表情`）**给到哪层就存哪层，空层不建目录**：

| 写法（都配一张图） | 落点 |
|------|------|
| `摸摸头` | `自定义/综合/摸摸头.gif`（只给表情名） |
| `今汐` / `捏捏` | 命中角色 → `自定义/今汐/…`；命中画师 → 该画师目录下 |
| `捏捏 比心` | `捏捏/比心.gif`（画师 + 表情名） |
| `捏捏 今汐 比心` | `捏捏/今汐/比心.gif`（三层） |
| `画师:新画师 角色:新角色 表情:新表情` | 本地没有也照此新建 |

- **新建画师一定用 `画师:名字`**：纯参数模式下认不出的词一律当表情名，不会乱建画师目录；
- 画师名优先复用本地目录（精确同名 → 忽略大小写与空格 → 模糊包含）；多个命中会列出来让你回序号；
- 名字含空格照原样写（如 `MIX CRAFT`）；上传完自动重建索引；权限默认仅主人。

## 📁 数据目录

`gsuid_core/data/MingChaoBQ/`，索引为自动生成的 `index.json`，图片支持 `.gif/.png/.jpg/.jpeg/.webp`：

```
data/MingChaoBQ/
├── 画师名/角色名/[子分类/]   # 子分类可选，直接放图也行
├── API/                      # API 拉取的图，按角色自动分目录
├── icons/                    # 自定义图标，覆盖内置图标
├── statistics.json           # 统计（自动生成）
└── banner.png / bg.png       # 帮助图横幅与背景（文件名可在控制台改）
```

新增或删除图片后执行一次 `bq更新索引`。

## 🐧 Linux / Docker

- **下载器**：API 取图优先调用系统 `curl`（绕开 Cloudflare 的 TLS 指纹拦截），没有 `curl` 时回退 `aiohttp`，官方镜像已自带；
- **代理 / 字体**：`curl` 与 `aiohttp` 都读 `HTTP_PROXY` 等环境变量；渲染优先用 GsCore 自带 MiSansVF，不装系统字体也能出图；
- **路径**：索引内路径统一用正斜杠，Windows 与 Linux 之间搬运后可直接使用。
