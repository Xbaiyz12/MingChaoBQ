# 图标目录

图标文件名 = 角色名或画师名.png
尺寸：150x150 像素，透明底 PNG

## 命名示例
- 通用.png          兜底图标
- 爱弥斯.png        角色「爱弥斯」的图标
- 捏捏.png          画师「捏捏」的图标
- cmd_random.png    帮助图里某条命令的图标

## 优先级
1. data/MingChaoBQ/icons/ 下的同名文件（用户自定义，优先）
2. 本目录下的文件（插件默认）
3. 通用.png

用户想覆盖某个图标，只需把同名文件放到：
  gsuid_core/data/MingChaoBQ/icons/
